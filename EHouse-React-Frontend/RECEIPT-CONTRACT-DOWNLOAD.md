# Receipt & Contract Download

Only the receipt/contract report behavior was changed. Existing dashboard, payment, booking, authentication and auto-refresh behavior is preserved.

Click **Receipt** or **Contract** after a seller-confirmed payment. The report window now provides:
- **Download Receipt/Contract** — saves a self-contained HTML report to the device Downloads folder.
- **Print / Save as PDF** — uses the browser print dialog so the user can choose **Save as PDF**.

The report keeps the MAHA E-HOUSING logo, watermark, property, customer, seller and payment information, plus signature sections.
